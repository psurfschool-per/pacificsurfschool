# Pacific Surf School - Website

Página web oficial de Pacific Surf School en Playa Barranquito, Lima, Perú.

## 🚀 Ver la página

Abre `index.html` en tu navegador o usa un servidor local:

```bash
python -m http.server 3000
```

Luego abre: http://localhost:3000

## 📁 Estructura

```
/
├── index.html          # Página principal
├── styles.css          # Estilos
├── app.js             # JavaScript (modal, formulario, animaciones)
└── img/               # Imágenes
    ├── logo.jpeg      # Logo oficial
    ├── hero.jpeg      # Banner principal
    └── galeria1-7.jpeg # Fotos galería
```

## ✅ Optimizaciones aplicadas

- ✅ Imágenes en formato JPEG optimizado
- ✅ CSS minificado
- ✅ Fuentes Google solo con pesos necesarios
- ✅ Lazy loading en imágenes de galería
- ✅ Sin dependencias externas pesadas
- ✅ Responsive mobile-first
