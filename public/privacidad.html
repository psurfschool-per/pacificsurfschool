2. Datos personales recopilados

En el proceso de reserva y prestación de servicios, recopilamos los siguientes datos personales:

  • Datos de identificación: Nombre completo.
  • Datos de contacto: Número de WhatsApp, correo electrónico.
  • Datos físicos: Peso (kg), altura (cm) — opcionales, para ajuste de equipo.
  • Datos de experiencia: Nivel de experiencia en surf, nivel de habilidad.
  • Datos de pago: Información de tarjeta de crédito/débito procesada por Culqi (no almacenamos datos de tarjeta).

3. Finalidad del tratamiento

Los datos personales son recopilados para:

  • Gestionar y confirmar la reserva de clases de surf.
  • Enviar confirmación de reserva por correo electrónico y WhatsApp.
  • Personalizar la experiencia del cliente (ajuste de equipo, selección de nivel).
  • Procesar el pago correspondiente al servicio contratado.
  • Enviar información sobre servicios, promociones y novedades (solo con consentimiento expreso).
  • Cumplir obligaciones legales y tributarias.

4. Base legal del tratamiento

El tratamiento de datos personales se fundamenta en:

  • La ejecución del contrato de prestación de servicios solicitado por el titular.
  • El consentimiento expreso del titular para el envío de comunicaciones comerciales.
  • El cumplimiento de obligaciones legales (Ley N° 29733 — Ley de Protección de Datos Personales).

5. Compartición de datos personales

Los datos personales pueden ser compartidos con:

  • Culqi: Para el procesamiento de pagos en línea. Culqi actúa como encargado del tratamiento bajo sus propias políticas de privacidad.
  • EmailJS: Para el envío de correos de confirmación de reserva.
  • Autoridades competentes, únicamente cuando exista obligación legal.

No vendemos ni compartimos datos personales con terceros para fines de marketing.

6. Conservación de datos

Los datos personales serán conservados por el tiempo necesario para cumplir con la finalidad para la que fueron recopilados y durante los plazos establecidos por la legislación vigente. Los datos de transacciones de pago se conservan conforme a las normas tributarias y contables aplicables.

7. Derechos del titular

De acuerdo con la Ley N° 29733, los titulares de datos personales tienen derecho a:

  • Acceso: Conocer qué datos personales tenemos sobre usted.
  • Rectificación: Solicitar la corrección de datos inexactos.
  • Eliminación: Solicitar la eliminación de sus datos personales.
  • Oposición: Oponerse al tratamiento de sus datos para fines específicos.
  • Revocación del consentimiento: Revocar en cualquier momento el consentimiento otorgado.

Para ejercer estos derechos, comunicarse a: info@pacificsurfschool.com.pe

8. Seguridad de los datos

Implementamos medidas de seguridad técnicas y organizativas para proteger los datos personales contra acceso no autorizado, alteración, divulgación o destrucción. El procesamiento de pagos se realiza a través de Culqi, quien cumple con estándares PCI DSS de seguridad de datos.

9. Uso de cookies

Nuestro sitio web puede utilizar cookies y tecnologías similares para mejorar la experiencia del usuario, analizar el tráfico y personalizar el contenido. El usuario puede configurar su navegador para rechazar cookies.

10. Cambios en la política de privacidad

Nos reservamos el derecho de modificar esta política de privacidad en cualquier momento. Los cambios serán publicados en esta página con la fecha de última actualización.
